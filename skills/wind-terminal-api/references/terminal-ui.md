# Wind 终端 EDB 元信息检索路径

2026-09-29 已通过当前 Mac 的 Wind 金融终端实测。此路径只辅助发现与核验指标；观测值仍由 WindPy MCP 查询，元信息来源单列为 `wind_terminal_ui` / `Wind 金融终端 EDB 界面`。

## 已验证入口

- 应用 bundle ID：`com.wind.mac.Windotd`，名称 Wind金融终端。
- 按 CUA 工具的文档选择应用，读取当前可访问性树。不要把示例中的元素序号固定在脚本中。
- 点击终端底部的“代码/名称/简拼/功能”，输入 `EDB`。先核对候选“经济数据库”，再确认进入。
- EDB 页面顶部有可编辑搜索框，支持关键词和完整指标代码。用当前可访问性树里的文本栏设置值，再按 Return。
- 结果分“按层级”“按指标”等。先查看地区、单位、频率、原始机构和“停止”状态；必要时调整关键词或筛选。
- 选中候选后，打开“指标速览”。详情提供指标 ID、名称、单位、频率、来源、起止时间、更新时间及定义。部分年月日期另有完整日期输入框，不要自行补成不存在的公布日。
- 根据已观察信息保存本地元信息证据，再用 `register_economic_indicators` 导入；`metadata_source_id=wind_terminal_ui`。保留已有 Alice 导入记录，不把 UI 信息伪称为 API 元信息返回。

## 当前机器的界面行为

独立 `com.wind.mac.api` 应用曾多次返回 `noWindowsAvailable`，后来从终端命令 `CG` 进入并重新选择 Wind API 后，坐标点击一度恢复，可打开“工具 → 指标查询”和 EDB 向导。其控件大多不提供可访问性文本，必须读截图，不能把 UI 错误解释成取数权限错误。之后错误又出现，因此该路径仍不稳定。

在指标查询中，按分类展开节点，双击叶子指标可显示字段、参数和释义。本次通过此路径确认了 `fund_mgrcomp`、`issuerupdated`、`oper_rev`。输入框的键盘/粘贴和滚动曾无效；不要在未见结果变化时声称搜索成功。坐标只对当次截图有效。

在 `com.wind.mac.Windotd` 中，EDB 和 API 帮助页的网页控件可通过可访问性元素操作，是已验证的另一入口。

EDB 输入框曾出现“等待应用读取剪贴板超时”。确认页面状态后使用工具提供的 setValue，再按 Return 可以提交；不要使用其他桌面自动化工具绕过 CUA。

一次查询提交后先读取新状态；若请求尚在加载，可在完成独立工作后再次读取。当前元素序号会变化。不要批量保存模板、订阅提醒、发起分享或调用 Alice 洞察；这些不是指标发现所需步骤。

## 实测案例

- `大豆 港口 库存` 返回当前进口大豆港口库存与多条停更的港口分项。`S0117164` 为“中国:港口库存量:进口大豆”，日频、吨、汇易网。
- 直接搜索 `S0112945` 返回“中国:产量(估计年度):豆粕”，月频、百万吨、美国农业部。该指标的定义指向市场年度的产量；每月观测与自然月产量不同。
- `豆粕 库存` 查到原 126 项目录之外的 `V0103973`：“中国:沿海:库存量:豆粕”，周频、万吨、来源“根据新闻整理”。WindPy 试取 2026-09-01 至 2026-09-29 得到 4 个周度观测，独立 MCP stdio 调用亦通过，证据为 `verification/mcp-catalog-extension.json`。
- 当前 UI 查询证据位于项目 `verification/wind-terminal-ui-metadata.json`。UI 历史范围不证明 API 同样可取，二者需分别验证。

此流程不等于 MCP 获得了一个公开的 WindPy 全库搜索函数。MCP 本地目录检索和终端 UI 发现须向用户说明其各自范围。

## 2026-10-04 补充核对

终端网页控件的可访问性元素点击、setValue与Return本轮可用；这不代表独立Wind API窗口的坐标点击问题已修复。详情见项目`references/edb-terminal-metadata-20261004.json`。

按代码搜索也可能返回同名的多来源分组。必须读取最终打开的详情中的实际指标ID；不能把输入搜索框的代码当作所有候选的代码。螺纹钢旧候选S5716165直接检索无结果，按名称找到H6924748和K4569350；后者末值与旧候选相同，但未证明是别名。多晶硅S9988490搜索分组先显示百川盈孚额外付费提示，取消后另一Wind来源行的实际代码为S5100860，不自动替代原候选。

速览头部的起止时间表示展示的历史范围，下方图形日期可能默认只选一年；不要把图形起点写成全历史起点。BDI单位与地区栏空白应保持未知，不能按常识补成“点”。
