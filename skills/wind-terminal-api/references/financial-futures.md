## 额度错误与继续查询

2026-09-30中证1000长历史请求返回 `-40522017`、`CWSDService: quota exceeded.`，回执 `97e8fe5212844235ad7a9f398e5aeb3b`，当时停止新增取数。后一次请求产生 `WSD: SkyClient request failed`，回执 `26c646341c08461fa89515fe2d9736c5`，不按数字错误码推断成权限问题。2026-10-03确认连接可用后，相同完整请求成功，回执 `3cb60468958d444392a459748693c5b0`；旧错误原样保留，不再作为当前不可用的判断。成功也没有测得剩余额度或重置时间。

0.21.0保留兼容错误码 `WIND_UPSTREAM_ERROR` 和原始回执，额外返回 `error_category="quota_exceeded"`、`automatic_retry_recommended=false`。只有上游实际错误文字包含额度超限，才做此分类；单凭数字错误码不推断。批量EDB查询遇错会保留已完成指标及回执并停止后续指标。

`wind_status(connect=false).quota_observation` 只扫描当前本地配置最近100条失败回执，不读取实时余额。过去发生过额度错误不等于现在仍超额；没有错误记录也不等于额度充足。Wind官方[FAQ第23项](http://114.80.154.45/ApiHelpCenter/web/webapp/manual/id-3218ff17-dbc3-4691-b473-18eabf697c77)解释了额度超限，但未提供本账户的具体额度与重置时间；本地可通过 `search_wind_documentation("quota", document="api_faq")` 查阅。

后续仍需核对其他收益率期限、资金利率单位与长历史，以及股指基差、国债CTD及IRR的历史范围和口径。复用已保存的成功回执，避免重复下载四类已完成指数历史。受限的第三方产品单列权限缺口，不绕过订阅限制。
