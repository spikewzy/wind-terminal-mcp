# EDB 元信息与官方导出

数值通道为 `wind_terminal_api`；从终端界面确认的元信息单列 `wind_terminal_ui`。CSV 解析候选使用 `wind_terminal_ui_export`，不能因来源栏或页脚写着 Wind 就认为文件来源和原始口径已独立验证。保留发布者 `source`，例如国家统计局、隆众资讯。

## 已验证的路径

1. 通过 `search_economic_indicator(scope="terminal")` 获取 WAI 候选，保留同名异码和未知口径。
2. 在 Wind 金融终端输入 EDB，按代码搜索；选中实际指标后打开“指标速览”或添加至指标表。核对代码、现行名称、单位、频率、发布者、地区、起止区间及更新时间。指标表的公式应为空，智能换算应关闭；不要用加工后的显示信息代替原始定义。
3. 若需要保存批量表头，可从官方“数据导出”选择 CSV、简体中文、列方向；勾选指标名称、指标ID、频率、单位、来源，建议同时包含国家、时间区间、更新时间。保留原文件、指纹与导出选项。当前只完成了一份单指标 CSV 的实际导出；六列联合导出在界面操作超时后尚未确认完成。
4. `parse_wind_edb_export(csv_text, evidence)` 只解析已解码文本，不访问文件或 Wind，不计算公式，不导入数值或自动登记。文件可用 `.venv/bin/python inspect_edb_export.py /绝对路径/export.csv --evidence "导出时间、界面和选项"` 检查；支持 UTF-8、GB18030，最多4MB、500指标列。
5. 解析结果中的 `export_metadata` 是显示表头。原始 `unit/freq/source` 保持空值，因为 CSV 不完整记录变频、单位转换、计算及填充规则。核对原始指标定义和必要的 WindPy 数值后，才把确认过的字段交给 `register_economic_indicators`，注明证据。纯导出候选不能直接用于按频率选取最近N期。
6. 使用 `query_economic_indicator_data` 读取明确日期范围。保留 API 原始回执；导出文件是独立的核对材料，不替换 API 结果。
