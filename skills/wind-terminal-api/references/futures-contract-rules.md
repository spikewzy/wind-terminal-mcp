## 主力与次主力的判定

第7—9页、第16—17页说明的是自2020-05-01生效的规则，文档列的适用范围含国内和海外商品、股指、国债、外汇期货。

1. 每个品种只保留一个主力；最后交易日当日的月合约不参与主力判定。
2. 收盘后，如有同一个月合约的成交量、持仓量均为最大，选为新的主力，下一个交易日生效。
3. 若不满足上述条件，通常维持原主力；但如果原主力在成交量、持仓量两项上都不再居首，则必须重新选择。
4. 重新选择时先比较成交量；并列时比较持仓量；仍并列时选近月。
5. 次主力先排除主力，再采用相应规则；最后交易日排除、双指标判定、维持或重选以及次交易日生效的要求同样适用。

这些说明不是可直接复算全部历史的完整程序规格。初始化、缺失值、同时失去资格等边界仍需核查；文档规则与Wind实际历史映射尚未逐日比对。本服务尚未新增自动主力选择器。
