# 国内期货调用与覆盖

数据来自 `wind_terminal_api`。本服务仍面向所有资产；此处记录用户要求的国内商品、金融期货及基本面验收，日线优先、基本面历史优先。实时状态和覆盖证据从 `wind_capabilities.data_coverage` 读取，静态样本不代表当前账户权限或新上市品种。

主连、次主连、近月连续、固定月份连月及品种指数的区别，见[期货虚拟合约规则](futures-contract-rules.md)。2026-10-04已读取终端官方28页PDF的规则说明并保存带页码摘要；没有新增自动主力选择、换月价格调整或逐日历史规则认证。

## 按品种找到已有查询示例

`search_wind_query_recipes`现支持“沪铝 仓单”“尿素 仓单”“甲醇 仓单”“30年期国债 净持仓”等关键词组合。90项产品的中期协名称及已核对Wind显示名，关联到40条既有请求；返回`product_discovery.products`中的实际请求代码、目录标签和逐代码历史数据数量。短关键词可能匹配多个品种，不自动消除歧义，也不裁剪原批次。

例如`AL00.SHF`、`UR00.CZC`的六日仓单各6格非空，`L_F00.DCE`六格全空；后者是塑料月均价，不能用`L00.DCE`的值替代。各代码的原始零、空值分别计数；单位与上游来源未知时仍留空。WSET表格的逐品种计数留空，不强行把可交割券等表格行当成期货时间序列。

此功能复用已有目录和回执，没有新增数据下载。产品参照仍为2026年8月中期协表与9月29日Wind目录，不是当前品种全集或全历史认证。原84条请求、日期和证据保持不变；新安装没有开发回执时，`runtime_query_verified=false`与嵌入的历史统计分开理解。索引见项目`references/futures-product-discovery.json`。
