# 基本面指标的选择与验证

本文件规范 `wind_terminal_api` 的研究流程，不是 Wind 全库指标字典。字段存在、账户可取、含义正确、适合回测须分别验证。

## 先确定数据类型

| 问题 | 优先入口 | 必须确认的口径 |
| --- | --- | --- |
| 农业现货价格、库存、产销、进出口、供需预测 | EDB 指标目录 → `query_economic_indicator_data` | 地区、品种、品质、贸易条款、频率、单位、原始机构、统计期 |
| 公司财报、估值、盈利预测 | `search_wind_fields` 查本地证据，陌生字段由 CG 确认，再通过 WSS/WSD 取数 | 报告期、单季/累计/TTM、合并范围、归母与整体、金额单位、是否为预测 |
| 期货价格、结算价、持仓量 | WSD/WSI/WSQ | 具体合约或连续合约、交易时段、结算/收盘、复权与换月规则 |
| 成分、持仓、专题报表 | WSET 或 WSS | 表名、参数、报告期、公布日、样本池及历史变更 |
| 新闻、公告、研究报告 | 各自的已验证文档接口 | 新闻不能代替研报；标题不能代替全文；存在 SDK 函数不能证明内容可取 |

## 一个指标至少需要说明什么

记录 `code/name/unit/freq/source`；此外按任务记录地域、品种/规格、统计范围、现货或预测、原值/同比/累计、营销年度或自然年度、季调/未季调、税费和币种。目录没有的内容保留未知，不能由相近名称自动补全。

`inspect_economic_catalog` 查看本地目录构成。`search_economic_indicator` 支持 `filters={"freq":"周","unit":"万吨","source":"原始机构名称"}` 的精确过滤；过滤未命中只说明这个本地目录没有匹配条目。关键词结果仍是候选，不得自动选取首项取数。

开发环境早期曾导入126条农业候选元信息作为研究样本，来源为先前Alice目录：日30、周20、月32、季1、年43。新安装默认目录为空，不导入这些样本，也没有农业优先级。查询值由WindPy读取；目录记录数不能解释为账户覆盖数。

## 从 Wind CG 增补陌生指标

1. 在 Wind 终端或 Wind API 的 EDB/指标查询/代码生成器中确认代码与定义。官方说明入口：<https://www.wind.com.cn/mobile/ClientApi/zh.html>。
2. `parse_windpy_query(code=<单条 w.edb/w.wss/w.wset 查询>)` 将生成的查询转成 `method/arguments`。解析不执行 Python，也不验证权限或口径。不要粘贴登录凭据或其他脚本。
3. 以较短、明确的日期范围试取，核对代码、日期、维度和几个已知数据点。原始回执保留成功、失败与空值。
4. EDB 的确认元信息通过 `register_economic_indicators` 登记。使用真正的元信息来源与证据；不能把历史 Alice 目录重新标成 Wind CG。指标说明变化时保留新证据。
5. 扩大到正式历史范围之前，检查真实可取起止日期。接口返回成功不能替代日期核验；开始日期不能仅依赖目录中的 beginDate。

示例仅展示结构，代码须使用实际确认值：

```json
{
  "indicators": [{"code":"S0117164","name":"经核对的完整指标名称","unit":"吨","freq":"日","source":"原始发布机构"}],
  "metadata_source_id":"wind_api_ui",
  "evidence":"实际 Wind CG 导出文件路径或明确说明，含核验日期"
}
```

上述占位名称不可原样登记。2026-09-29 已用终端 EDB 界面重新核对 S0117164、S0112945，并发现原目录之外的 V0103973；三者当前元信息标为 `wind_terminal_ui`，历史 Alice 导入证据保留。当前目录 127 条，124 条仍是 Alice 候选元信息。以 `inspect_economic_catalog` 为准。

## 已核对的证券基本面陷阱

`search_wind_fields("营业收入", method="wss")` 返回 `oper_rev` 的官方释义及成功请求，分别列 `official_definition_observed` 和 `successful_sample_available`。另有 `statement_value_evidence`：茅台2024/2025年度、rptType=1/2、unit=1的四项字段共16个值，已与正式年报的合并/母公司报表人民币元金额一致。`net_profit_is` 在该合并样本中对应含少数股东损益的净利润，不能当作归母净利润；其完整 Wind 官方释义仍未取得。范围、页码、回执及失效规则见[财务报表样本核对](financial-statements.md)。

软件自带目录已提供更广的候选，见 [本地目录读取](bundle-metadata.md)。其中报表类型表的标签可直接查看，但它与每个接口字段的正式绑定并未全部提供。`unit=10000` 的营业收入试验没有按“万”缩放；新样本只核对 unit=1，不认证其他数量选项。额外选项、其他主体和报告期须另行确认，2024年比较列也不代表当时发布版本。

- 官方指标查询将 `fund_mgrcomp` 定义为基金管理公司全称，与基金经理姓名 `fund_fundmanager` 分开；基金管理人的界面来源为基金公告。前者已在 510300.SH 实测成功，旧猜测 `fund_corp` 返回无效指标，不能继续复用。
- `issuerupdated` 是当前债务主体，可随债务承继或主体变化而更新；ABS 和集合债另有特定主体口径。它不能证明历史发行时的主体，不能无说明替代“原始发行人”。已在 240011.IB 试取成功。
- 内地股 `oper_rev` 不必然只反映最新正式财报。官方释义说明：在正式报表未披露、已有快报的情形可使用快报数据；新会计准则前的数据可能经过 Wind 调整。研究需额外确认披露类型与当时可得时间。
- 这些字段说明来自 `wind_api_ui`。详细选项、全部报表枚举和逐点发布日期没有因此自动认证。证据见项目 `verification/wind-api-ui-fields.json`。

## 农业数据常见区别

- 港口库存、油厂库存、社会库存及商业库存统计范围不同；地区和机构更换可能形成断点。
- 产量、出口量等可能按自然年、作物年度或营销年度统计。USDA 的年度供需数也可能是某个发布月份的预测版本，不等于当年最初已知值。
- 价格可能有不同含税、交货地点、规格或币种；港口到岸与工厂交货不可直接当作同一价。
- “万吨”“百万吨”等单位已包含量级；目录另有 magnitude 不代表还需要重复放大。蒲式耳的重量换算需按商品及标准确认。
- 零可能是真实观测；空值可能表示无发布、无权限或缺失。不要把零一律当缺失，也不要跨断点自动前填。
- 基差需要现货与期货的质量、单位、地点及合约选择一致；连续合约的换月会改变价差含义。
- 压榨利润需明确原料成本、产出率、产品价格和加工费用。不要把固定产出率或运费假设写成供应商原始数据。

## 派生计算与回测

`combine_economic_series` 只对原始 EDB 回执的共同观测日期计算显式算术公式。它不自动换单位、补缺失或按发布时间对齐。结果保存公式、输入回执、各指标元信息及问题日期。

派生回执的 `input_metadata` 取自计算时的本地目录，明确标记 `metadata_scope=current_catalog_at_analysis`；这不是下载当时随原始 API 值返回的字段说明。

回测数据应区分 observation_date（统计期）、publication_time（公布时间）、available_at（策略实际可用时间）、fetched_at（此次下载时间）与 vintage（数据版本）。当前普通 EDB 查询不能提供这些字段中的全部，未知项保持空值，`point_in_time_safe=false`。

若只有观察日期，结果可以用于描述性研究，不能声称已通过无前瞻偏差的历史策略验证。下载快照比较只能识别开始保存之后观察到的修订，不能恢复过去未保存的版本。

Wind 的产品更新记录提及 EDB 初值和 field_info；不能由此推断当前 MCP 已实现这些选项。须以当前版本的真实生成代码、返回结果和字段说明为依据，再扩展对应能力。

## 文档优先顺序

已安装官方 WindPy 签名 → 当前 Wind CG 的指标说明及生成代码 → 版本对应的 Wind 使用手册 → 有依据的小样本 Wind 调用。第三方技能或示例可以提供线索，不能替代代码、单位、权限及发布时间核验。无需为了使用常规接口先上传整本手册；陌生指标的定义与 CG 示例通常更有价值。

## 财务季度序列

2026-09-30 实测 WSD 的 `Period=Q;Days=Alldays` 保留 2024-03-31、06-30、09-30、12-31 四个季末，营业收入和净利润均返回四个非空值；不加 Days 时，前两个日期变为 03-29、06-28 且这两个字段缺值。报告期不是公布日，Period=Q 也不能独自证明单季增量口径。

同次请求中的 `eps_basic` 全空；API 请求成功不证明每个字段都存在有效数据，也不能仅据此认定账户无权限或全库无数据。字段检索返回 `successful_query_available`、`successful_sample_available` 和逐例 `value_availability`，须分开阅读。证据为 `verification/financial-calendar-probes.json`。
