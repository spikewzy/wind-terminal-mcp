# 中文财务问题到 WindPy

来源为 `wind_terminal_api`，适用于 v0.15.0 的有限范围自动解析。`stock_data/get_stock_fundamentals` 可直接接收下述问题；没有调用 Alice 的解析服务。其他字段或复杂问题仍需经过核对的 `resolved_request`。

## 支持的输入

问题需明确证券、报告期和人民币元单位。报表类型需明确；只有归母净利润的含义要求合并口径时，才允许省略并在计划中记录推定。证券名称由官方 WAI fer 识别；字段和报表选项使用已核对的 WSS 样本映射，不使用 WAI 返回的数字财务指标 ID。

| 含义 | 接受的名称 | WSS 字段 |
| --- | --- | --- |
| 营业收入 | 营业收入 | `oper_rev` |
| 净利润 | 净利润 | `net_profit_is` |
| 资产总计 | 资产总计、总资产 | `tot_assets` |
| 负债合计 | 负债合计、总负债 | `tot_liab` |
| 归属于母公司股东的净利润 | 归母净利润、归属于母公司股东的净利润、归属母公司股东的净利润、归属于上市公司股东的净利润 | `np_belongto_parcomsh` |
| 营业利润 | 营业利润 | `opprofit` |
| 所有者权益合计 | 所有者权益合计、股东权益合计、所有者权益（或股东权益）合计 | `tot_equity` |
| 货币资金 | 货币资金 | `monetary_cap` |
| 财务费用 | 财务费用 | `fin_exp_is` |

也可使用表中的英文字段名。营业收入不替代营业总收入，净利润不替代归母净利润。茅台合并报表样本的净利润包含少数股东损益，详见[财报核对](financial-statements.md)。

归母净利润只对应合并报表，明确要求母公司单体报表会报错。所有者权益合计在合并报表中含少数股东权益，不能替代归母净资产；财务费用保留原始正负号。

- 日期接受 `2025-12-31`、`2025/12/31`、`20251231`、`2025年12月31日`，或明确的 `2025年报` / `2025年度`，后者转为12月31日。单独 `2025年` 不自动推定为年报。
- 合并报表、合并口径或合并对应 `rptType=1`；母公司报表、母公司口径或母公司对应 `rptType=2`。
- 例如“贵州茅台2025年报净利润与归母净利润，单位元”由归母字段含义确定合并口径，计划会记录 `statement_scope_inference` 及依据字段；不能仅因一个报表类型有样本就推定口径。其他缺口径的问题仍要求明确。
- 明确写 `单位元`、`单位人民币元`、`人民币元` 等，使用 `unit=1`，不自动缩放。
- 自动路线仅覆盖 WAI 明确识别为中国股票、代码符合 A股格式的证券。最多50个不同代码、4个日期与报表类型组合、2000字单段问题。
- 多个证券、日期、字段和报表类型须分别成组列出。比如“茅台和五粮液的2024年报与2025年报母公司营业收入和净利润”表示这些维度的组合；若维度交错出现，停止并要求显式计划，不猜测对应关系。

## 调用

先看查询计划，可调用 `plan_wind_fundamentals`：

```json
{
  "question": "查询贵州茅台2025-12-31合并报表的营业收入、净利润、资产总计和负债合计，单位元"
}
```

该工具会调用一次 WAI 识别并保存计划，但不取财务值。计划包含 `codes`、字段及报表证据、原始识别和 SHA256、将要执行的 WSS 请求。

直接执行同一问题，用 `call_alice_tool_on_windpy`：

```json
{
  "server_type": "stock_data",
  "tool_name": "get_stock_fundamentals",
  "params": {
    "question": "查询贵州茅台2025-12-31合并报表的营业收入、净利润、资产总计和负债合计，单位元"
  }
}
```

此例生成：

```python
w.wss("600519.SH", "oper_rev,net_profit_is,tot_assets,tot_liab", "rptDate=20251231;rptType=1;unit=1")
```

直接执行也会自行识别并保存计划；暂不接收预览计划 ID 作为执行参数。已明确证券代码的问题仍使用 WAI 核查证券类别。既有显式 `resolved_request` 路线保持可用。

## 歧义、缺失与证据

“中国平安”实际返回 A股、港股和 ADR 三项。所有备选均保留，不按置信度选首项。写明 `中国平安（601318.SH）` 或 `A股中国平安` 可消除这一歧义；名称与括号代码必须匹配，A股限定与代码市场冲突时停止。

问题中的全部有实质含义的文字都需被解释。ROE、每股收益、扣非归母净利润、归母净资产、筛选条件、汇总、同比、TTM、单季、截至某时点、发布日期、其他币种或单位等尚未接入这条自动路线。部分内容可以识别，不代表可以忽略剩余内容。缺少报告期、无法唯一确定的报表类型、字段或单位时，在 WAI 前就报错；识别之后出现歧义时，保存未解决计划且不发起 WSS。

每次自动执行分别保存：

1. 原始 WAI 回执和证券候选。
2. `fundamental_query_plan`：完整原问题、字段样本证据、文本解释范围、请求及来源指纹。
3. 每次 WSS 原始回执。
4. `fundamental_question_result`：计划 ID 与指纹、所有查询、按证券/字段/请求报告期组织的结果行。

结果行中的 `report_date_requested` 与 WSS 原始 `Times` 分开，不将查询快照日期标成财报日期。`source` 保留原上游值，未返回时为空，调用来源另外标记 `wind_terminal_api`。

`requested_unit` 记录人民币元请求；只有该证券、日期、报表和字段的数值与已保存年报单元格相符，才将 `unit` 标为元并设置 `unit_verified_by_statement_sample=true`。其他结果的 `unit` 为 null，不能将一个公司的样本推广成全库单位认证。

缺值保留 null，另列 `value_missing` 和 `missing_value_count`。`status=complete` 只表示所有计划请求已完成。实测五粮液2024/2025年母公司 `oper_rev` 均为空，母公司净利润有值；不能改用合并值或零补齐。某一 WSS 请求失败时，保存此前已完成查询与失败位置，并停止剩余请求。

历史发布日期、原始发布版本和全市场参数语义未因此补齐；结果保留 `point_in_time_safe=false` 和 `semantic_equivalence_verified=false`。
