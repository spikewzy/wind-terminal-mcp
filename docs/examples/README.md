## 300ETF 近月期权 IV 微笑

[查看用户提供的完整截图](300etf-iv-skew.png)。标的为 510300.SH；报价标记为 2026-09-30，近月到期 2026-10-28，ETF 报价 4.432 元，ATM 执行价 4.40 元。

- Wind 原生买卖中间价 IV：ATM 看涨 16.32%，看跌 16.25%，平均 16.285%，显示为 16.29%。
- RV20：21 个前复权收盘价构成 20 个日对数收益，样本标准差（ddof=1）乘 √252；结果 12.740783%。
- 溢价：16.285% − 12.740783% = 3.544217 个百分点；相对溢价约 27.817887%。
- 曲线采用低执行价看跌、高执行价看涨的虚值侧 IV，ATM 用两侧均值。买价 IV 为零的深实值合约保留异常状态，不当作有效零波动率。
- 原生 IV 的内部模型、年化日历及独立计算时刻未由接口认证；WSET 合约目录的历史时点成员资格也没有完整认证。报告没有宣称这些方法已经统一。

## 复现这些任务

复制主 README 的相应 prompt 到已安装本 MCP 的 harness。agent 需要有图表/文件生成功能，才能交付图、HTML 或 PDF；MCP 工具本身返回结构化数据与证据。新日期、新账号和不同数据权限会产生不同结果。明确记录报价时间、期权到期日、主力映射、现货规格、周频定义与公式后再比较。

本目录发布的是选定的研究成果，没有打包开发机器的原始回执库、客户端配置、账号信息或 Wind SDK。图表里的评级、目标和情景为分析假设，数据与第三方组件保留各自权利，见 [第三方说明](../../THIRD_PARTY_NOTICES.md)。
