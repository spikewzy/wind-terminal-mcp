# 本地查询预算

版本0.23.0在所有原生请求前预留本地预算，适用于通用查询、EDB、WAI、Alice适配、固定名单筛选及连接检查。它限制本服务发起的尝试次数及估算数据格，**不是Wind账户余额或计费统计**。

## 配置

配置位于实际数据目录的`query-budget.json`。未设置`WIND_TERMINAL_MCP_DATA_DIR`时，数据目录为安装目录下的`runtime`。`wind_status(connect=false).local_request_budget.policy_file`返回实际位置。

```json
{
  "schema_version": 1,
  "window_seconds": 604800,
  "max_native_calls": null,
  "max_estimated_cells": null,
  "max_estimated_cells_per_request": null
}
```

缺少配置或限额为`null`时，该项不拦截；`0`为明确禁止。三个限额分别为滚动窗口内请求尝试数、累计估算数据格及单次估算数据格。限额须由使用方按研究任务设定，不能直接把Wind尚未确认的额度当成这些数值。604800秒为本地默认七天窗口，可配置；不表示账户每天或每周定时清零。

本次升级未替用户填写限额。多个客户端必须使用同一数据目录及包含此功能的新版本才能共享控制；不同数据目录、旧服务器进程、终端界面及其他Wind脚本不受此预算限制。首次启用只统计此实现之后的预留记录，不将旧回执追认为全部历史消耗。修改配置在下一次原生请求前读取，宜使用原子文件替换；无效配置阻止新原生请求，状态诊断和缓存读取仍可使用。

## 数据格估算

- WSS/WSEE/WSQ：请求代码数乘字段数。
- WSD/WSES/EDB及TDAYS：按包含非交易日的自然日格估算，支持明确日期及日、周、月、季、半年、年周期；不会额外调用交易日历。低频数据也按全日格保守计算。
- TDAYSOFFSET/TDAYSCOUNT：一个结果格。连接检查估为零数据格，但占一次请求尝试。
- 分钟、逐笔、专题表、实体识别等不能由这些参数可靠估算的返回，记为未知。如果启用数据格限额，会在发出请求前返回`LOCAL_BUDGET_UNESTIMATED`；只启用请求次数限额仍可访问这些方法。窗口内曾有未知规模请求时，累计数据格限额也不能把它当零。

这是预期有效返回格数的估算，不是接口计费单位、实际返回行数或Wind用量的保证上界。`plan_wind_data_queries`分别返回全计划与各分页请求的`data_volume_estimate`，不会分割日期、缩小范围或执行查询。

## 执行与继续

同一数据目录的SQLite事务将预算检查和预留合并，多进程不能同时花掉最后一次预算。失败、超时及进程中断的预留均保留；无自动退款或重试。原始回执与预算预留相互关联，缓存命中和只读本地检索不新增预留。

超本地预算返回`LOCAL_BUDGET_EXCEEDED`，字段`account_quota=false`；配置错误返回`LOCAL_BUDGET_CONFIG_ERROR`。这些错误不能当成Wind权限或额度错误。EDB批量查询保留已完成值与回执，并明确列出当前尚未发送的代码；固定名单筛选保留既有继续回执，不跳过被拦截批次。

`wind_status(connect=false).quota_observation`继续保存最近一次上游超限错误，并寻找该**相同方法、相同参数**之后的成功回执。某条请求恢复不表示其他请求、函数或全账户都恢复；余额和恢复时间继续留空。后续成功如存在本地数据校验失败，会同时显示，不能只看上游错误码。

## 验证边界

并发预留、缓存、超时、滚动窗口、未知规模及批量中断均通过本地测试；MCP集成验证在临时数据目录启用小预算，使用超预算请求验证在连接Wind之前被拦截，不消耗真实Wind数据额度。旧进程需要重新加载新代码；协议验收不代表WorkBuddy应用内调用已验收。
